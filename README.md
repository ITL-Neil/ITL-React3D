# test2element

这是一个空白 Vite + React + TypeScript 示例项目，用于演示如何直接使用上层目录的 `Element/ITL3D.tsx`。

## What this demo does

- 在 `src/App.tsx` 中直接硬编码 `RN3DElement` 参数。
- 在页面中用一个边框容器 (`.frame`) 承载 3D 渲染内容。
- 模型文件放在 `public/Hohenzollern_Castle_optimized.glb`，默认 `modelUrl` 可直接工作。

